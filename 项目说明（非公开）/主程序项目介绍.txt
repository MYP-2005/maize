玉米籽粒颜色提取与氮浓度预测系统项目介绍

一、项目简介

本项目是一个面向玉米籽粒图像分析与氮素相关指标预测的桌面应用系统。
系统以双目图像为输入，先通过图像处理模型自动提取籽粒颜色与形态特征，
再结合随机森林回归模型，对单样本的氮浓度 N 和氮素利用效率 NUE 进行预测。
项目采用 PySide6 构建图形界面，适合实验室批量样本分析、单样本快速预测、
结果导出和模型效果展示等场景。

二、项目目标

1. 实现玉米籽粒图像的自动化特征提取。
2. 根据图像和人工补充特征，对 N 和 NUE 进行预测。
3. 提供可视化、可交互的桌面界面，减少手工计算和重复整理数据的工作量。
4. 支持预测结果导出到 Excel，便于后续统计分析与实验记录保存。

三、主程序功能

主程序文件为 `_build_main.py`，核心功能包括：

1. 选择图片文件夹并加载样本图像。
2. 识别左右目图片，支持以 `_L` 和 `_R` 结尾的配对图像。
3. 调用 `yolo_sam_features.py` 进行图像特征提取。
4. 自动提取并显示颜色特征、形态特征和相关辅助指标。
5. 支持手动补充或修改部分特征值。
6. 调用随机森林模型预测 N 和 NUE。
7. 用进度条展示预测结果区间和等级。
8. 将样本信息、特征值、预测值和导出时间写入 Excel 文件。
9. 记录运行日志，方便排查图像识别、模型加载和预测过程中的问题。

四、系统工作流程

1. 用户打开主程序并选择图片文件夹。
2. 系统读取文件夹中的图片，并识别同一样本的左图和右图。
3. 用户选择目标图片后，程序启动后台线程进行图像特征提取。
4. 图像特征提取模块调用 YOLO + SAM2 相关流程，完成籽粒检测、分割和特征统计。
5. 提取结果回填到界面输入框，用户可以继续补充产量、百粒重、体积、容重等字段。
6. 程序将特征输入到随机森林模型，输出 N 和 NUE 的预测值。
7. 用户可将结果导出到 Excel，形成完整实验记录。

五、主要模块说明

1. `_build_main.py`
   主界面程序入口，负责界面交互、线程调度、特征回填、预测和 Excel 导出。

2. `yolo_sam_features.py`
   图像特征提取核心模块，负责调用 YOLO 与 SAM2 模型，并计算籽粒相关图像特征。

3. `MaizeDesider_GPT1.ui` 和 `MaizeDesider_GPT1_ui.py`
   分别为 Qt 界面设计文件和由其生成的 Python 界面文件。

4. `rf_N.pkl` 和 `rf_NUE.pkl`
   随机森林回归模型文件，用于最终的 N 和 NUE 预测。

5. `predict_single_sample.py`
   单样本命令行预测工具，适合调试模型或快速验证某条样本数据。

6. `yolo_sam_subprocess.py`
   图像特征提取的备用命令行入口，便于在子进程场景中调用。

7. `SF-2号模型.py`
   模型训练与单样本预测的辅助脚本，包含模型训练、评估和示例预测逻辑。

六、模型与依赖

项目运行时依赖的核心模型和文件包括：

1. `best.pt`
   YOLO 检测模型，用于初步定位图像中的目标籽粒。

2. `sam2.1_hiera_tiny.encoder.onnx`
   SAM2 编码器模型。

3. `sam2.1_hiera_tiny.decoder.onnx`
   SAM2 解码器模型。

4. `rf_N.pkl`
   用于 N 预测的随机森林模型。

5. `rf_NUE.pkl`
   用于 NUE 预测的随机森林模型。

项目主要依赖库包括：

1. PySide6
2. OpenCV
3. NumPy
4. Pandas
5. Joblib
6. OpenPyXL
7. ONNX Runtime
8. Ultralytics
9. PyTorch
10. scikit-learn

七、界面与交互特点

1. 支持文件夹批量导入图片。
2. 支持左右图配对识别，适合双目采集场景。
3. 支持自动提取，也支持手动录入特征。
4. 支持预测结果等级显示，便于快速判断样本水平。
5. 支持右键选择 Excel 导出目标文件。
6. 支持运行日志记录，便于定位异常问题。

八、输出结果

程序可输出以下信息：

1. 图像提取后的颜色特征和形态特征。
2. 单样本 N 预测值。
3. 单样本 NUE 预测值。
4. N 和 NUE 的等级判定。
5. 导出到 Excel 的结构化样本记录。
6. `analysis_results` 目录中的中间分析结果。

九、运行方式

1. 安装项目所需依赖库。
2. 确保模型文件与程序文件放在约定目录中。
3. 启动 `_build_main.py` 运行主界面。
4. 选择图片文件夹并导入样本。
5. 执行特征提取和模型预测。
6. 如需快速测试单条样本，可运行 `predict_single_sample.py`。

4. 如果需要他人复现，建议在 README 中写明模型文件的获取方式和放置位置。

十一、总结

本项目实现了从玉米籽粒图像特征提取到 N、NUE 预测的完整流程，
兼顾了自动化、可视化与实验数据导出需求。主程序界面集成了图像加载、
特征提取、模型预测和结果管理等功能，适合用于科研实验、样本分析和
模型应用展示。
